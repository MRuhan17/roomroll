Roomroll

Roomroll is a browser-based tabletop platform for running role-playing game sessions online.

The goal of Roomroll is to reduce friction in online tabletop play by keeping sessions lightweight, reliable, and under the control of the Dungeon Master. Players join lobbies, participate in sessions in real time, and interact through chat, dice rolls, and a shared tabletop surface.

This repository contains the early-stage codebase for Roomroll and is under active development.

Project Status

Roomroll is currently in early development. The focus is on building a stable core that allows small groups to run a full session end to end without desynchronization or data loss.

Features, structure, and implementation details are expected to change rapidly at this stage.

Repository Structure

This repository uses a monorepo layout with clear separation between frontend and backend code.

roomroll/
├── frontend/    Client-side application
├── backend/     Server-side application and real-time services
└── README.md

Core Principles

Roomroll is built around a few simple principles:

Sessions should be easy to start and resume

The Dungeon Master retains full control

Real-time interactions must be reliable and authoritative

The platform should feel like a shared room, not a complicated tool

Development

Roomroll is being developed as a private project. Documentation will evolve as the platform stabilizes.

Additional setup instructions and contribution guidelines will be added when the project reaches a more mature stage.
