# Future Roadmap

This document outlines the planned future enhancements and milestones for the RoomRoll project. All items listed here are **Planned** and not yet implemented.

## Milestones

### Phase 1: Core Stability & Performance (Planned)
- Implement Redis for Socket.IO state management to replace in-memory state.
- Add robust error reporting and frontend telemetry.
- Optimize database queries with proper indexing strategies for large campaigns.

### Phase 2: Multi-Agent AI System (Planned)
- Introduce a multi-agent system where different NPCs can interact autonomously.
- Expand prompt engineering to support complex logic and deeper contextual awareness.
- Implement token-usage tracking and cost optimization for OpenAI API calls.

### Phase 3: Administration & Billing (Planned)
- **Admin Panel:** Create a dashboard for managing users, monitoring active rooms, and viewing system health.
- **Billing & Subscriptions:** Integrate Stripe for tiered usage plans (e.g., limits on AI generation or room participants).

### Phase 4: Advanced Gameplay Features (Planned)
- Custom Map uploads and grid snapping.
- Deep integration for D&D 5e / Pathfinder character sheets and automated roll modifiers.
- Fog of War and Dynamic Lighting.

## Feature Backlog
- In-app text and voice chat.
- Mobile-responsive optimization for player views.
- OAuth integration (Google, Discord, GitHub).
